# 数据集使用指南

卡片上显示的句子来自**数据集**。一个数据集就是一个 JSON 文件中的一组摘抄，导入后保存在应用自己的数据库里。

---

## 基本操作

右键点击卡片 → **「数据集」**：

| 菜单项 | 效果 |
|---|---|
| 数据集名称（N 条） | 勾选表示启用。卡片从**所有启用的数据集**中随机抽句，每一条被抽到的机会相同 |
| 导入数据集… | 选择一个 JSON 文件导入，导入后自动启用 |
| 删除数据集 › 名称 | 确认后删除该数据集 |

- 启用哪些数据集会被记住，下次打开应用时保持不变。
- 想"合并"几个数据集，同时勾选它们即可；不需要的时候取消勾选，原数据不受影响。
- 首次打开应用时会自带一个「示例」数据集，可以随时停用或删除，删除后不会再自动出现。

## 导入的文件格式

UTF-8 编码（可带 BOM）的 JSON 数组，每一项是一条摘抄：

```json
[
  {
    "id": "老子/道经/第一章#0",
    "text": "道可道，非常道；名可名，非常名",
    "translation": "可以用言语说出来的“道”，就不是那恒常不变的“道”……",
    "lang": "lzh",
    "path": ["老子", "道经", "第一章"],
    "source": "老子"
  }
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 在本文件内唯一，不能为空 |
| `text` | 是 | 原文，不能为空 |
| `translation` | 否 | 译文 |
| `lang` | 是 | 语言代码，如 `lzh`（文言文） |
| `path` | 是 | 目录层级，字符串数组 |
| `source` | 是 | 出处 |
| `extras` | 否 | 任意扩展内容（JSON 对象） |

用仓库中的数据管线可以把 NiuTrans 古文语料转成这种格式：

```sh
npm run pipeline -- <NiuTrans 根目录> <书名目录> <输出 JSON 路径>
```

导入时的规则：

- 数据集名称取自文件名；与已有数据集重名时自动加上序号，如「史记 (2)」。
- 内容完全相同的文件不能重复导入。
- 文件最大 512 MB。格式不对、id 重复或为空、text 为空时整个文件不会导入，并提示原因。
- 导入的内容会复制进数据库，之后原文件可以移动或删除。

## 数据存放位置

所有数据集保存在一个 SQLite 数据库文件 `library.db` 中。

**便携版**：在 exe 同目录的 `ExcerptsData\library.db`，卡片（`ExcerptsData\cards`）、设置与 WebView 缓存也都在这个文件夹里。

**安装版**：

- Windows：`%LOCALAPPDATA%\io.github.YoungZ2357.excerpts\library.db`
- macOS：`~/Library/Application Support/io.github.YoungZ2357.excerpts/library.db`
- Linux：`~/.local/share/io.github.YoungZ2357.excerpts/library.db`

数据集可能很大，所以放在本地数据目录，不随 Windows 账户漫游。卡片与设置仍在 `%APPDATA%`（漫游目录）下。

备份时请先退出应用，再复制 `library.db`。删除这个文件会清空所有数据集，下次启动时重新生成，并只包含「示例」。
