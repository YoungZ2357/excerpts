# 卡片使用指南

Excerpt 每次会在一张“卡片”上显示一句摘抄。卡片决定这句话**看起来是什么样子**：用什么字体、字多大、放在哪里、窗口多大。

你可以直接使用内置的卡片，也可以自己做一张。

---

## 基本操作

| 操作 | 效果 |
|---|---|
| **左键**点击卡片 | 换下一句 |
| **右键**点击卡片 | 打开菜单：切换卡片、管理数据集（见 [数据集使用指南](datasets.md)）、重新加载卡片、打开卡片文件夹 |

在右键菜单里选中的卡片会被记住，下次打开应用时还是这一张。

---

## 内置卡片

### 经典

默认卡片。从上到下依次显示：

- **原文**：思源宋体粗体，较大，暖墨色
- **译文**：在一条短分隔线下方，思源宋体细体，字更小、颜色更浅
- **出处**：固定在右下角，显示为「《书名 · 章节》」

原文和译文整体在卡片中略偏上的位置居中。

适合想同时看原文和译文的时候。

### 极简

只显示原文，放在卡片正中间，字号更大。译文和出处都会隐藏。

适合当作桌面上的一句“座右铭”。

### 竖排

竖长的卡片，仿古籍排版：

- **原文**：竖排，从右往左成列
- **出处**：做成小印章，放在左上角
- **译文**：在虚线下方横排显示
- **章节**：显示在右下角

适合读古文的时候。

> 内置卡片不能被修改或覆盖。想在它们的基础上调整，请新建一张自己的卡片（见下文）。

---

## 什么是卡片

一张卡片就是一份“样式说明”，告诉应用怎么摆放这句话。卡片上可以显示四样东西，我们称为**元素**：

| 元素 | 内容 |
|---|---|
| 原文 `text` | 摘抄的句子本身 |
| 译文 `translation` | 这句话的翻译或解释 |
| 出处 `source` | 来自哪本书，比如“道德经” |
| 目录 `path` | 这句话在书中的位置，默认隐藏 |

### 可自定义内容

**整张卡片**
- 窗口大小
- 四周留白
- 元素之间的间距
- 背景颜色
- 圆角

**每个元素**
- 字体
- 字号、粗细
- 行距、字间距
- 颜色、透明度
- 左对齐 / 居中 / 右对齐
- 横排 / 竖排
- 显示或隐藏
- 放在卡片上的任意位置

### 只写想改的部分

新建卡片时，需基于已有卡片编写期望修改的部分，未编写内容则与其父类相同，若未指定父类则以“经典”为基础。

比如只想把原文换成楷体，就只写字体这一项，其余的字号、颜色、位置全都沿用经典。

你也可以选择以“极简”或你自己做的另一张卡片为基础。

## 如何创建一张卡片

### 第 1 步：打开卡片文件夹

右键点击卡片，选择 **「打开卡片文件夹」**。系统会打开一个文件夹，你的卡片都放在这里。

### 第 2 步：新建一个卡片文件

在这个文件夹里新建一个文本文件，把扩展名改成 `.json`，例如 `kaiti.json`。

文件名要求：

- 只能用**小写英文字母、数字、`-` 和 `_`**，例如 `kaiti`、`my-card`、`card_2`
- 不能叫 `classic`、`naive` 或 `vertical`（内置卡片已经占用了这些名字）

保存时请选择 **UTF-8** 编码（Windows 记事本默认就是）。

### 第 3 步：写入卡片内容

先从最简单的开始，复制下面的内容到文件里：

```json
{
  "schemaVersion": 1,
  "id": "kaiti",
  "name": "楷体"
}
```

- `schemaVersion` 固定写 `1`
- `id` 和文件名保持一致
- `name` 是显示在右键菜单里的名字，可以用中文

这样已经是一张可用的卡片了，只是看起来和经典一模一样。接下来加上你想要的样式（见下面的例子）。

### 第 4 步：在应用里使用

右键 → **「重新加载卡片」**，然后在菜单里选中你的卡片。

之后每次修改并保存文件，只要再点一次「重新加载卡片」就能看到效果，不需要重启应用。

## 示例

下面的例子都可以直接复制使用。注意 `id` 要和文件名一致。

### 换一种字体

把所有文字换成楷体：

```json
{
  "schemaVersion": 1,
  "id": "kaiti",
  "name": "楷体",
  "style": {
    "base": { "fontFamily": ["KaiTi"] }
  }
}
```

`base` 表示“所有元素都这样”。

### 只改原文

原文更大、换成楷体，译文和出处不变：

```json
{
  "schemaVersion": 1,
  "id": "big-text",
  "name": "大字原文",
  "style": {
    "slots": {
      "text": { "fontFamily": ["KaiTi"], "fontSize": 30 }
    }
  }
}
```

`slots` 里可以单独设置某个元素：`text` 原文、`translation` 译文、`source` 出处、`path` 目录。

### 在极简的基础上调整

用 `extends` 指定以哪张卡片为基础。这里在极简的基础上把字再放大一些：

```json
{
  "schemaVersion": 1,
  "id": "huge",
  "name": "特大号",
  "extends": "naive",
  "style": {
    "slots": {
      "text": { "fontSize": 44 }
    }
  }
}
```

## 常用设置速查

**整张卡片**（写在 `style` 里）

| 写法 | 含义 | 例子 |
|---|---|---|
| `size` | 窗口宽、高 | `{ "width": 480, "height": 360 }` |
| `padding` | 四周留白：上下、左右 | `[24, 28]` |
| `gap` | 元素之间的间距 | `12` |
| `background` | 背景颜色 | `"#f4efe4"` |
| `radius` | 圆角大小 | `8` |

**元素**（写在 `base` 或 `slots` 的某个元素里）

| 写法 | 含义 | 例子 |
|---|---|---|
| `fontFamily` | 字体，可以写多个备选 | `["KaiTi", "SimSun"]` |
| `fontSize` | 字号 | `24` |
| `fontWeight` | 粗细，300 细、400 常规、700 粗 | `700` |
| `lineHeight` | 行距，字号的倍数 | `1.8` |
| `letterSpacing` | 字间距 | `0.1` |
| `color` | 文字颜色 | `"#2b2b2b"` |
| `opacity` | 透明度，0 到 1 | `0.6` |
| `align` | 对齐：`left` / `center` / `right` | `"center"` |
| `writingMode` | 排列：`horizontal` 横排 / `vertical` 竖排 | `"vertical"` |
| `visible` | 是否显示 | `false` |

**位置**（只能写在 `slots` 的某个元素里）

| 写法 | 含义 | 例子 |
|---|---|---|
| `position` | 放在卡片的哪里。`x`、`y` 是从左上角算起的百分比，`anchor` 指元素的哪个点对准这个位置：`top-left` 左上角 / `center` 中心 / `bottom-right` 右下角 | `{ "x": 50, "y": 50, "anchor": "center" }` 正中间 |
| `maxWidth` | 最大宽度，占卡片宽度的百分比 | `90` |

## 关于字体

- **写字体的名字，不是文件名。** 例如 `KaiTi`（楷体）、`SimSun`（宋体）、`Microsoft YaHei`（微软雅黑）。
- 可以使用**电脑上已经安装的字体**。查看字体名：Windows「设置 → 个性化 → 字体」，点开某个字体看到的名字就是。
- 也可以使用**应用自带的字体**，目前有思源宋体，写作 `Source Han Serif SC`。
- 可以写多个字体作为备选，例如 `["方正书宋", "SimSun"]`：第一个没有时自动用第二个。全都没有时，会用经典卡片的字体。
- 有些字体本身只有一种粗细，这时改 `fontWeight` 可能看不出变化。

## 遇到问题

**卡片没有出现在右键菜单里**
- 检查文件扩展名是不是 `.json`（注意不要变成 `kaiti.json.txt`）
- 检查文件名是否只有小写字母、数字、`-`、`_`
- 改完后是否点了「重新加载卡片」

**右键菜单里出现「⚠ 有 N 个卡片问题…」**

点开它可以看到具体哪里写错了，例如少了逗号、数值超出范围、拼错了设置名。按提示修改后重新加载即可。

**某项设置没有效果**
- 写错的设置不会让应用出错，只会被忽略，并沿用经典卡片的样式。请查看上面的「卡片问题」提示。
- 字体名写错时**不会**有提示，只会退回备选字体。如果字体没有变化，请先检查字体名。

**改坏了怎么办**

随时可以在右键菜单里切回「经典」。删除或修复出问题的文件后，重新加载即可。
